# Strange Loop

Build Python flows that can check a result, revise an upstream output, and reuse completed work. This documentation covers the replay prototype in `strange_loop`.

From the checkout, run `uv sync` to install the project. The examples use deterministic Python stages and require no model credentials.

- Follow the [three-query tutorial](tutorial.md) for a complete run with batching, a timeout, and two ways to correct a query.
- Open the [User Guide](guide/overview.md) for short, independent examples of each concept.
- Use the [API reference](reference.md) to look up a signature or version field.
